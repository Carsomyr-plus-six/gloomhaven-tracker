# Icons

These icons come from the **Gloomhaven Creator Pack** by Isaac Childres / Cephalofair Games, which he shares under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) ([BoardGameGeek thread](https://boardgamegeek.com/thread/1733586/files-for-creation)).

They were changed for this site. Each page was converted from PDF to SVG, cropped to its artwork, and given coordinates rounded to one decimal. `heal`, `shield` and `refresh` were also recoloured from black or white to the site's text colour. In the item slot icons, the white details were turned into see-through cut-outs. The single-colour icons (`checkmark`, `slot-*`, `class-*`) are used as masks, so the page fills them with the colour of the text around them.

These files are therefore licensed **CC BY-NC-SA 4.0**, not under the AGPL-3.0 that covers the rest of this repository. You may use them for non-commercial purposes with credit, and anything you make from them must carry the same licence.

They are generated, so don't edit them by hand. To remake them from the pack, run:

```
py tools/creator_pack_icons.py "path/to/Creator Pack V2.zip"
```

The tool lists which page of the pack each icon comes from.
